# DSA Lab Linked List Assignment (C++)

In this repository, I have presented my C++ solutions to the **Linked List Assignment** assigned in the **Data Structures and Algorithms Lab-1** course.

The purpose of this assignment was to develop a practical command over singly linked list operations by implementing every task manually through pointer manipulation, without relying on any built-in linked list libraries.  
To preserve clarity and organization, I solved each problem in a separate `.cpp` file while carefully following the required input and output specifications.

---

## Problems I Solved

The repository includes solutions to the following linked list problems:

1. Build and Print a Train Route  
2. Count and Sum of Elements  
3. Insert at Any Position  
4. Delete by Value  
5. Search and Report  
6. Reverse the Delivery Route  
7. Merge Two Sorted Patient Queues  
8. Find the Kth Node from the End  
9. Rearrange / Interleave Two Halves of a Linked List

---

## Concepts I Strengthened Through This Work

While completing this assignment, I was able to deepen my understanding of several important linked list techniques, including:

- Creating and connecting nodes
- Traversing a linked list efficiently
- Insertion and deletion at required positions
- Searching for one or multiple occurrences of a value
- Reversing a singly linked list in-place
- Merging two sorted linked lists
- Applying the two-pointer method
- Performing advanced in-place rearrangement
